## 本次范围

- 知识库选择必须进入实际文本编辑器的内容流，仅显示灰色、小字号标题，作为绑定稳定库 ID 的原子引用；取消输入框上方独立 chips。不能以边框内的静态标签冒充可编辑内容。
- 用户可在引用前后移动光标，用 Backspace、Delete、跨引用选区删除或剪切移除；撤销/重做同步引用与会话选择。普通正文仍可独立输入、替换、复制和换行。
- Lexical 替换 textarea 输入叶子，以保留编辑、撤销和 IME 行为；提供明确的聚焦/选区 imperative handle，尺寸测量使用独立 DOM ref。保留现有工具栏、mention、附件、场景插入和重试流程。
- 会话知识库选择仍经真实 Go 命令持久化，正文与选择分开。引用标题和 ID 不拼入正文 payload。异步 CAS 队列合并快速连续编辑的最新意图；失败重新读取并恢复权威引用，同时保留普通正文并提示重试。
- 紧凑滚动选择器不变：整行选中变色、无右侧复选小框，名称下一行灰字摘要/逻辑目录/文档数，首批 10 项、触底追加、最多 5 个库；合成目录仍明确标记测试数据。
- Stage 1 带库发送仍被前端和 Go 阻止，保留草稿；未选库沿用原聊天流程。真实个人/共享知识库、检索、上下文注入和服务部署均不在本次范围。
- 只有真实库目录导航链接留待 Stage 2：将来使用服务端提供且经可信地址校验的目标，删除引用不能触发导航。本次不为合成引用创建链接。

## 集中验收步骤

1. **位置与目录。** 打开本次核验来源的测试 EXE，在已有正文的光标处选择知识库。确认灰色小字号标题位于真正可编辑内容流，上方无独立 chips；点击/方向键可把光标放到引用两侧。目录仍支持摘要搜索、滚动加载第 11/12 项、5 库上限；第 6 库拒绝不改变已确认状态。
2. **普通删除与正文保持。** 在引用前后输入不同文字，分别用 Backspace、Delete 移除引用；选择“文字＋引用＋文字”后删除，核对只移除选区。Ctrl+A 后删除或剪切，再撤销/重做；核对引用数量、会话选择与普通正文一致，正文没有被引用标题替换。复制/剪切只输出可见纯文本（可包含标题），不输出隐藏库 ID 或可迁移的引用身份；粘贴的标题是普通文字，不自动选库。实际发送正文排除原子引用的标题及 ID。
3. **快速操作与失败。** 连续快速删除、撤销、重新选择多个引用，等待队列结束，核对最终界面与 Go 持久化一致且不超 5 库。使用受控失败/冲突测试观察恢复权威引用、错误和重试；普通正文的新编辑必须保留。保存或加载未完成时不应误发；最后引用只有确认移除后才解除选库阻止。
4. **会话与身份。** A/B 分别写不同正文并选择不同库，执行 A→B→A 和保存迟到场景；核对引用和正文不串会话。重开同一会话验证 Go 恢复；换账号/租户后清理旧引用并重新读取，不采纳旧身份迟到响应。
5. **IME 与换行。** 中文输入法组词时 Enter 只上屏；普通 Enter 按现有规则发送，但有库仍明确阻止且保留正文。Shift+Enter、多行纯文本粘贴、光标/选区跨引用、Home/End 和全选保持正常；窄窗口、滚动及调整输入区高度无溢出遮挡。
6. **原输入流程。** 验证 @技能、/智能体、#文件，场景插入后的占位符选区，插件页追加正文与聚焦，修改原提问/取消恢复；验证图片/文件粘贴与拖放、附件移除仍可用。替换正文不应隐式丢失持久选库，引用名称/ID 不混入附件说明或正文 payload。
7. **阶段边界。** 有引用时发送、运行中补充、重新生成、AskUser 回答和计划执行继续明确阻止，历史与草稿可恢复；移除并保存全部引用后原聊天可用。引用当前不能打开真实库目录，不把普通模型回答称为知识库回答。
